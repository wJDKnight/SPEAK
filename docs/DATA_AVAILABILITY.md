# Data Availability

The processed inputs supporting the reported SPEAK analyses, row-level spatial-domain
annotations, benchmark results, machine-readable figure source data, model request and
response records, fine-tuning inputs, spatialLIBD deconvolution artifacts, and integrated
MERFISH objects are available in Figshare at
https://doi.org/10.6084/m9.figshare.33043091. The deposited files cover STARmap samples
BZ5, BZ9 and BZ14; spatialLIBD/Visium samples 151507–151510 and 151669–151676;
MERFISH samples MERFISH_25–MERFISH_29; and COPD Xenium sample 230267_Slide2.

The GitHub repository at https://github.com/wJDKnight/LLMiniST contains the SPEAK source
code, configurations, analysis workflows, a compact STARmap example, and three small
machine-readable source-data tables. Original public datasets reused in this study remain
subject to their source licences and should also be cited using the identifiers reported in
the manuscript.
