# Dataset workflows

Each directory contains the retained research workflow for one paper dataset. Notebook
outputs and execution counts have been removed. The compact STARmap inputs are included in
GitHub; complete inputs, reported numeric outputs and expensive intermediates are distributed
through Figshare and resolve to the documented `examples/` paths after download.

Run notebooks with the repository root as the working directory so that `src/`, `configs/`
and `examples/` resolve consistently.
