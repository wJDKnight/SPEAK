# Visium / spatialLIBD workflow

Scope: 151507–151510 and 151669–151676. After downloading the Figshare data
package, each `examples/visium_libd/<sample>/` directory contains the analysis matrix,
`metadata.tsv`, spatial coordinates, and matching
`celltype_proportions_<sample>.csv`.

The exact model and latent artifacts used for reported analyses are deposited under
`examples/intermediates/visium_libd_deconvolution/`.
